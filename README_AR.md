# AI RSHAD PRO — النسخة الأولية

هذه نسخة أولية قابلة للتعديل من تطبيق ويب تقدمي (PWA)، بواجهة عربية واتجاه RTL.

## ما يعمل الآن
- واجهة متجاوبة للهاتف والكمبيوتر.
- تبويبات إنشاء صورة، تجهيز طلب فيديو، تجهيز طلب تحريك صورة، ومكتبة محلية.
- تجربة توليد صور اختيارية عبر نقطة خدمة عامة من Pollinations. هذه الخدمة خارجية وغير مضمونة، وقد تتغير أو تتطلب شروطاً مختلفة.
- حفظ سجل الطلبات في `localStorage` على نفس المتصفح.
- دعم التثبيت على الشاشة الرئيسية عند استضافة التطبيق عبر HTTPS.

## ما لا يعمل بعد
- لا يوجد مولّد فيديو فعلي موصول.
- لا يوجد محرك فعلي لتحويل الصور إلى فيديو.
- لا توجد حسابات مستخدمين أو مزامنة سحابية.
- لا تضع مفاتيح API السرية داخل `app.js` أو ملفات الواجهة؛ يستطيع أي زائر رؤيتها.

## تشغيله
1. ارفع محتويات هذا المجلد إلى استضافة تدعم HTTPS وملفات المواقع الثابتة.
2. افتح رابط الموقع من Chrome على أندرويد.
3. من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار.

يمكن تجربة الواجهة محلياً، لكن ميزات PWA تحتاج إلى HTTPS أو localhost.

## التطوير الآمن للمرحلة التالية
لربط نماذج توليد صور/فيديو حقيقية، أنشئ Backend وسيطاً (مثلاً Node.js أو Python) يحتفظ بمفاتيح API على الخادم، ويقدم نقاطاً مثل:
- `POST /api/image`
- `POST /api/video`
- `POST /api/image-to-video`

بعدها عدّل `app.js` لاستدعاء خادمك. اختر مزوّدات تسمح تراخيصها بالاستخدام التجاري الذي تريده، وتحقق من حدود الخطة المجانية وسياسة الخصوصية قبل الاعتماد عليها.

## الملكية
يمكنك تعديل ملفات HTML وCSS وJavaScript وتغيير الاسم والشعار والوظائف. هذه الملفات تمنحك ملكية نسخة المشروع البرمجية التي أنشأناها هنا؛ أما أسماء الخدمات الخارجية ونماذجها فتخضع لتراخيص وشروط أصحابها.
