# AI RSHAD PRO — النسخة المطوّرة التجريبية 2.0

تطبيق ويب تقدمي (PWA) بواجهة عربية واتجاه RTL. يتضمن استوديو صور، تجهيز أوصاف الفيديو وتمديده وتحريك الصور، أدوات صوت المتصفح، والترجمة.

## ما يعمل فعلياً في هذه النسخة

- **توليد الصور:** اتصال مباشر بـ AI Horde عبر مفتاح الاستخدام المجهول `0000000000`. يعتمد على أجهزة متطوعين؛ لا يتطلب شراء رصيد، لكن الأولوية منخفضة وقد يطول الانتظار أو لا يتوفر عامل مناسب. تُترجم الأوصاف إلى الإنجليزية عبر MyMemory عند اختيار لغة غير الإنجليزية، ثم تُرسل إلى AI Horde.
- **قراءة النص بصوت:** عبر Web Speech API والأصوات المثبتة أو المتاحة على جهاز المستخدم.
- **التعرف على الكلام:** عبر SpeechRecognition إن كان المتصفح يدعمه. قد يستخدم خدمة تعرف سحابية تابعة للمتصفح/النظام، ولا يعمل في كل الأجهزة أو اللغات.
- **الترجمة النصية:** عبر MyMemory Translation API. الحد المجاني المجهول المنشور هو 5,000 حرف يومياً. قد تختلف الجودة والتغطية حسب اللغة.
- **حفظ سجل الأعمال:** في localStorage على الجهاز نفسه.
- **تثبيت PWA:** عند الاستضافة عبر HTTPS.

## ما لم يتم ربطه بعد (ولا ندّعي أنه يعمل)

- توليد الفيديو من النص.
- تمديد الفيديو بالذكاء الاصطناعي.
- تحويل الصورة إلى فيديو.

لا يوجد في ملفات المشروع الأصلية مزوّد فيديو أو خادم خلفي. ولا يمكن تشغيل نماذج الفيديو الثقيلة على GitHub Pages كاستضافة ثابتة. يلزم لاحقاً اختيار محرك فيديو مفتوح المصدر وتشغيله على جهاز/خادم يدعم النموذج، أو مزوّد API مجاني بحدود واضحة. لم نضع زر توليد وهمياً لهذه الميزات.

## التشغيل والنشر

1. فك ضغط مجلد المشروع.
2. ارفع **محتويات المجلد** إلى مستودع GitHub، مع الحفاظ على أسماء الملفات.
3. فعّل GitHub Pages من إعدادات المستودع إن كان متاحاً.
4. افتح رابط الموقع عبر HTTPS. امنح إذن الميكروفون عند استخدام الإملاء الصوتي.

## الخدمات والخصوصية

- الصور والوصف المرسل إلى AI Horde يذهبان إلى خدمة خارجية وأجهزة متطوعين؛ لا ترسل محتوى خاصاً أو حساساً.
- الترجمة ووصف الصورة قد يُرسلان إلى MyMemory عند الحاجة للترجمة. الحد المجهول المجاني المعلن 5,000 حرف يومياً: https://mymemory.translated.net/doc/usagelimits.php
- AI Horde: https://api.stablehorde.net/docs/image/ و https://aihorde.net/api/
- Web Speech API: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API
- لا توجد مفاتيح API سرية داخل ملفات الواجهة. المفتاح المجهول الخاص بـ AI Horde عام بطبيعته وأولويته منخفضة.

## ملاحظات مهمة

- هذه النسخة لم تُختبر من داخل حساب GitHub Pages الخاص بك؛ يجب اختبار الخدمات من الرابط المنشور بعد الرفع.
- قد يمنع المتصفح بعض الاتصالات أو التنزيلات بسبب CORS أو سياسات الخدمة، وقد تتغير الخدمات المجانية وشروطها.
- لا توجد خدمة مجانية مضمونة بلا حدود أو زمن انتظار.
